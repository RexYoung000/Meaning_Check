# 验证与验收

## 已有覆盖

建档阶段暂无业务代码或自动化测试，未运行真实模型调用、未加载 Dia。文档完成不等于实现或产品验收完成。

## 拟实施检查

| 场景 | 规则 / 预期 | 类型 | 依据 |
|---|---|---|---|
| 关联 / 去重 | current、parent、root 正确；引用与相邻帖子不能替代；父根去重 | 单元 + 浏览器 | product / architecture |
| 补齐 / 缺失 | 10 层、30 秒；失败需选择后才分析 | 集成 + 浏览器 | product / architecture |
| 动态页面 | 新回复出现入口；导航清理；X 原按钮不受损 | 浏览器 | DESIGN |
| 请求控制 | hover 不调用，重复点击不重复付费，取消无旧结果 | 集成 + 浏览器 | product |
| 校验 | 拒绝无效 JSON、无效来源、伪造引用、截断结果 | 单元 + 模拟接口 | architecture |
| 密钥 / 历史 | 网页不能读密钥，保存 / 删除可用，无持久文本结果 | 浏览器 + 包检查 | architecture |
| UI | 明暗、窄窗、键盘、Escape、外部点击、媒体提示 | 浏览器 + 真实 Dia | DESIGN |
| 工程 | 类型、测试、构建、最小权限、无凭据包 | 自动化 | AGENTS |

## 待验证与缺口

真实 Dia / X 页面验证：定位父链、窗口边界、正常页面交互及清理。模拟网页不能单独证明 X 当前 DOM 兼容。

配置本地密钥后，选 10 条真实公开英文回复，覆盖真诚、中性、玩笑、讽刺与缺上下文；对照字面翻译记录理解增益、依据质量、耗时和用量。首批最多 20 次实际调用，用户主动重试也计入。不把用户反馈当作对方真实动机或准确率标签。

任何虚构证据或无依据的人身恶意判断都须修复复测。最终体验由 Rex 验收，不能替代代理自测。
