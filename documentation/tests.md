## 缺口与验收边界

1. **真实模型尚未验证**：当前真实调用为 0 次；本地配置完成尚未获得可验证证据。不能报告实际准确性、速度或费用。
2. **实际 X / Dia 兼容性尚未完整验证**：公开 X 页面结构已读取并用于适配，但模拟夹具通过不等于真实插件链路通过。DOM 或登录限制变化时可能补齐失败，应用提供部分分析 / 重试 / 手动补充。
3. **引用帖与其他复杂渲染**：读取各帖主正文，不把嵌入引用帖当成父帖；引用内容本身、长文展开及其他插件的所有兼容情况尚未完成真实覆盖。
4. **Rex 的使用体验与理解价值待验收**：不能用代理自测替代。任何虚构依据或无依据的恶意判断都须修复复测。

验收路径：Dia 扩展管理 → Meaning Check → Details → Extension options → 保存密钥 → 打开候选回复 → 点击常驻入口 → 帮我确认意思。缺上下文时应先显示选择；结果应先有一句中文主解读，再有语气和可回看的原文依据。
