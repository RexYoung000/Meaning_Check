# 产品规则

## 定位与阶段

Meaning Check 是开源浏览器插件，帮助理解公开交流中的意思、语气和依据。2026-10-14 完成 0.2 的 BYOK、双语及网站管理；0.3 按 Rex 的实际使用反馈改为每条回复下方独立卡片、多任务排队、加载计时和直达设置。0.3.1 修正独立帖、正文展开和二次等待状态，已在真实 Dia 的独立帖上完成两次 DeepSeek 请求。规则已实现，自动化结果及真实 Dia / 厂商质量的边界记录在 tests.md；视觉与理解价值仍由 Rex 验收。

采用 MIT 许可、用户自带 API（BYOK）。先不做打赏或广告；没有业务服务器、账号、分析历史、自动发送、回复生成或整页翻译。

## 模型与配置

支持 xAI / Grok、OpenAI / GPT、Anthropic / Claude、Google / Gemini、GLM、DeepSeek、千问、Kimi、MiniMax 官方 API，以及自定义兼容接口。Claude Code 是使用 Claude 的工具，不作为独立模型或登录凭据接入。型号、接口和来源统一维护在 models.md；保留 DeepSeek V4.1 Flash（deepseek-flash）及 Grok 4.6。

多个连接配置可保存，只启用一个；模型以完整名称显示，API ID 可查看。预置列表、用户主动刷新账号可用型号、手填 ID 并存。保存、选择和刷新不自动调用推理。连接测试须用户点击，使用固定短示例，提示可能产生费用；保存不代表连接已验证。没有自动换模型、跨厂商回退或自动重发付费请求。

密钥仅在本地扩展设置页输入，后台及可信扩展页面可读；网页不能读。更换接口地址清空未保存密钥并要求重新输入。升级迁移已有 DeepSeek 配置，不覆盖已有连接，不在文档、源码和日志保存凭据。

## 语言与引导

界面支持中文 / English，默认跟随浏览器界面语言（中文使用中文，其他使用英文），切换入口始终可见。解读输出独立设置：默认使用完整浏览器语言，也可选择常见语言或填写语言代码；原文引用保留原文。更改语言不自动重算已有结果。

首次安装、旧版首次升级打开一次引导，设置中可再次打开。引导包括配置模型、语言和网站、免费静态示例，以及加载、刷新页面、找到和固定工具栏入口的方法。静态示例不得冒充真实 API 结果。

## 网站与入口

默认开启 X 与 Reddit 的公开讨论回复；可全局暂停或单站关闭。站点由来源地址及路径列表管理，路径中的 * 匹配任意字符，同站多个路径满足任意一个即可。用户可新增、修改和删除；新增站点需浏览器站点授权。后续官方适配入口再增加。

X / Reddit 回复旁常驻小图标及「帮我确认意思 / Check meaning」，只有真实用户点击才处理，不接受网页脚本模拟点击。自定义网页使用选中文字入口，先确认可选背景再点击分析，不自动读取整页或推断父帖。不读取编辑框、私信、账号 cookies 或统计。Reddit 官方适配范围为 reddit.com / www.reddit.com 当前公开讨论页面；其他布局可按自定义网页选中文字使用。

## 上下文与解读

线程默认读取当前回复、直接父帖、原帖，父帖与原帖相同则去重，引用帖不替代父帖。支持纯文本、缩写、俚语和 emoji；图片 / GIF 不分析并明确提醒。

0.3.1 起同时支持独立帖子：已确认没有父帖的内容只分析当前正文，不把不适用的父帖 / 原帖列为缺失，也不拒绝原帖。明确的回复关系才补齐父链；未知关系不能伪装为已确认没有父帖，需显示实际范围和可选补充入口。展开判断只依据正文专用控件，不能把媒体、引用帖、翻译器或其他「展开」按钮当成文字截断。

时间线中未发现回复标记或连线的帖子，默认只解读当前文字，明确标注「未确认回复关系，本次只使用这条帖子」，允许可选背景；这是读取范围，不是宣称父帖不存在。详情页中尚未确认的父链、存在回复标记而父帖未读到的情况仍等待用户选择。每次再次分析重读当前页面中已选来源的文字及展开状态，不沿用已失效的截断标记，不覆盖手动补充。

缺上下文时以不抢焦点的插件临时页补齐，最多追溯 10 层、补齐最多 30 秒。补齐失败列出缺项，等待用户选择现有内容分析、重试或手动补充，不能静默分析。自定义网页的手动背景为可选内容，不冒充自动识别的原帖。

缺上下文、关系未识别和正文未展开分别提示原因；不能把全部失败统称为「缺上下文」。用户再次点击分析、补齐或手动提交时均立即显示动效、阶段与新周期计时；无效输入先给可执行错误，不能用虚假的模型等待状态掩盖。

先展示一句主解读，再展示语气、表达功能及 1–2 条原文依据。反驳不等于恶意，不猜私密动机；歧义放在结论后，方向无法确定时说明缺什么，不给虚构确定性百分比。引文必须来自实际输入，结果校验失败或截断不得冒充有效结论；网页及模型内容仅按文本显示。

每条回复下方独立展开卡片，可同时保留多个。重复点击同一回复展开 / 收起已有卡片，不重复计费。滚动、点击页面空白或其他回复不关闭卡片；关闭只取消该条任务，收起保持执行。离开页面、回复被移除或复用、暂停当前站点会取消受影响任务并清理插件临时页。用户自行导航过的页保留。回复入口、卡片和工具栏均提供「插件设置」直达入口。

## 运行边界与验收

输入上限 12,000 字符，输出上限 4,096 token。整个扩展最多同时执行两条解读操作，其余按点击顺序排队并可取消；排队不调用模型、不计入执行超时。一次主动操作含上下文和模型总计最多 60 秒；其中补齐最多 30 秒。加载显示阶段、动画、秒数和等待上限，上限不作为完成时间承诺。等待手动操作不计时，下次点击开启新周期。后台重启清理遗留资源并提示重试，不自动重新请求。

离线及模拟接口验证与真实解读质量分开。首批真实验证最多 20 次推理（含连接测试和主动重试），用 10 条公开回复比较字面翻译；记录耗时、用量、依据和理解价值。未在真实 Dia 或厂商 API 验证的能力明确标记。Rex 已授权公开 GitHub 仓库、中英 README 同步及个人主页重点展示；不据此发布扩展商店。
