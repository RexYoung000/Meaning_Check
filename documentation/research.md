## 2026-10-14 对齐结论

用户确认开源 MIT / BYOK、九家官方厂商与自定义接口；图标和常驻完整文本按钮、工具栏及一次引导降低开启与使用成本。浏览器扩展页面无法靠网页翻译器翻译的问题以自身中英界面解决，输出语言另跟随浏览器完整语言或手选。X / Reddit 默认启用，自定义网页采用主动选区，不引入整页采集。

DeepSeek V4.1 Flash 对应 deepseek-flash；Grok 4.6 与 4.7 同时保留。官方最新型号和接口来源集中在 models.md，阅读目录并不证明账号权限或真实质量。

## 0.3 使用反馈与交互调整（2026-10-14）

Rex 提供已安装 0.2.0 的截图：固定浮窗与回复脱离，长的缺上下文 / 手动补充表单被视口裁切；缺少加载动效和等待边界，连续查看多条回复时只能保留一张卡片。浏览器 Details 被误当成插件设置，不容易找到 Extension options。该反馈为实际体验证据，不是模型准确率证据。

据此确认并实施：每条回复原文下方独立展开、页面自然滚动、多条结果同时保留；两条并行其余排队，收起保持执行，关闭只取消对应任务。增加阶段动画、秒数与 30 / 60 秒等待上限；不展示内部思考或虚构完成百分比。回复入口与卡片常驻插件设置，工具栏及指南复用同一设置页；已打开的设置草稿不被覆盖。

仅借鉴用户描述的原位阅读交互，沿用现有原创图标和 DESIGN.md 视觉规则；没有引入第三方组件或浮窗库。已完成 30 个实际扩展模拟场景；Dia 重载和设置入口已确认，真实 X 观察到原位加载及补齐失败回退。多条实际浏览体验与厂商解读质量仍按 tests.md 记录待验收。

## 0.3.1 判定反馈与开源同步

Rex 提供独立帖子被误报缺父帖 / 未展开的截图，并指出再次确认缺少等待反馈。实际 X 首页的该帖子已完整显示；通过原生 DOM 检查确认它使用经典 tweet / tweetText / cellInnerDiv 结构，tabindex=0，当时没有正文专用 show-more 控件。不能用人工构造的现代页面夹具替代真实结构验证，也不能沿用之前缓存的截断标记。

据此新增独立帖与仅本条文字的读取范围，分别保留已确认无父帖、时间线未发现关联、已知回复缺父帖及关系未知。稳定的截断快照保留已读父链并提示正文问题，不等到超时把所有来源丢成缺失；二次操作重读既有来源并保留加载阶段。模型解释据称 / 转述等表达，不把新闻内容当作已验证事实。

用户明确授权公开 GitHub 仓库、中英 README 同步与个人主页重点展示。发布前核对现有仓库、公开文档链接与凭据；现有主页置顶项目保留。实际同步状态记录在 tests.md。

## 0.3.3 可读性、原文与主题帖反馈

Rex 提供真实结果与加载截图：主解读使用「当前帖子、父帖、前提」等术语，依据和背景过长，加载过程有重复解释。确认动作改为「帮我意图识别」，随界面语言变化；采用直白大意、简短语气 / 表达，依据与背景默认收起。保留条件、否定和不确定性，不靠删词或隐藏限制制造确定感。

新截图显示西班牙语原文被中文译文替代作为依据，并反馈只显示直接回应对象而漏掉主题帖。实现依据的改动是正文候选排除译文以及连续原生父链跨布局层关联，范围仍为当前、父帖、主题帖三份公开原文，不采集整页。模拟译文节点不证明所有翻译工具兼容；真实样本复测另记 tests.md。解读输出默认完整浏览器语言，支持其他 locale，中英范围只适用于界面。

真实 Dia 复测补充：该案例同时使用 X 原生自动翻译，而非仅由沉浸式翻译插入的译文。原生翻译会替换正文，因此增加临时页恢复原文。第一轮真实请求虽取得西班牙语原文，但误标为独立帖，只保留本条；不能算主题帖修复通过。元素面板确认经典 tweet / cellInnerDiv 结构与列表零偏移。后续保留用户页已识别父链，逐项恢复原文，避免用补齐页暂时仅有焦点的状态覆盖关系。结果和实际请求数在 tests.md 分别记录。
