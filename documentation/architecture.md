# 架构与数据边界

## 职责

保留 WXT 0.21.4、TypeScript 5.9.3、Manifest V3。内容脚本读取公开回复 / 用户选中文字并展示卡片；后台补齐上下文和调用模型；可信设置页管理连接、语言、网站及权限；工具栏弹窗显示状态和快捷开关；引导页提供安装及使用入口。没有业务服务器。

## 本地配置与迁移

ModelProfile 保存 id、名称、厂商、协议、基础地址、模型 ID 和测试状态；密钥仅放受保护的 storage.local。内容脚本只能接收不含密钥的公共设置、状态和解读结果。更改地址要求重新填写密钥，避免旧凭据被发送给新来源。关闭连接或切换模型不会自动推理。

旧 deepseekApiKey 在首次初始化迁入 DeepSeek V4.1 Flash 连接：先持久保存新结构，再移除旧项；迁移可重复运行，不覆盖已有配置。storage.local 设置 TRUSTED_CONTEXTS；页面请求按扩展 ID、来源、启用路径核验。模型测试及型号刷新仅允许可信扩展页面。

SiteConfig 保存来源 origin、路径列表与 enabled；多个路径为 OR，* 为通配。固定权限 storage、scripting、activeTab；默认 X / Reddit 和原有 DeepSeek 来源。其他站点 / API 使用可选 HTTPS 来源权限；自定义本地服务仅支持 HTTP loopback。动态注册自定义站点内容脚本，不预授予所有站点，不申请 cookies、tabs 或外部消息连接权限。

## 数据及模型接口

ContextBundle 保留 current / parent / root 引用、去重来源、缺项、警告和 thread / selection / post 模式；Post.origin 区分 x、reddit、web、manual。选中文字仅包含用户选区和可选手动背景，不能伪造自动父链。

0.3.3 的呈现与来源规则：X 的正文候选先排除译文容器，再从保留原文读取文字及 emoji；隐藏的原文可读取，已生成的译文不能替代原文。PageSnapshot 可携带连续原生连接线已确认的 root / rootDepth，在同一快照中保留当前、直接父帖、主题帖三份原文；不同布局包装层不构成断链，断开的连接线、未知祖先和超过 10 层的链不能跳过验证。resolveContext 优先使用已确认的根，否则沿父链继续读取。引用帖与其他分支不参与。结果结构与严格校验不变，提示词负责自然表达，界面负责默认收起依据和原文详情、去重来源标签。界面语言决定按钮文案，输出语言继续独立使用完整浏览器 locale 或用户设置。

切换语言等设置时，只更新确实变化的动态站点脚本注册。未变化的自定义来源不重新注入内容脚本，保留已经显示的选区入口及卡片；设置通知更新其按钮语言。新增 / 更换来源才注册并注入，删除或停用来源则撤销注册并通知现有页面清理。不能因语言切换让用户的选区消失。

X 原生翻译状态用 sourceIssue=translated 和空正文表示，仅允许作为启动定位信息；bundle 与最终快照拒绝这种来源。Collector 专属内容脚本在自己的临时页点击原生「显示原文」控件，再读取正文；用户页不点击该控件、不读取替换后的译文。只有已恢复的原文能进入 ContextBundle 和模型请求，超时仍走明确缺失 / 重试反馈。第三方只剩译文的状态 sourceIssue=original-unavailable 直接显示错误。

启动快照可保留已识别角色的空正文定位信息，逐项恢复原文后保留该关系；临时页暂时仅渲染焦点帖，不能覆盖用户页已确认的父链。经典 X 详情仅在祖先位于连续原生 cell、首帖位于列表零偏移且没有回复 / 缺口 / 广告信号时直接确认可见主题帖，非零偏移的最早可见内容保持未知。恢复文字和确认关系分开，最终模型材料仍须三角色原文校验。

0.3.1 新增 post 模式：parentState=none 转为仅含 current、missing=[] 的独立帖材料，角色不适用不等于缺失。重连及手动补充继续保留模式，模型提示明确当前内容为帖子或回复。X 正文展开控件必须属于主正文，排除隐藏、媒体、引用、翻译器及插件节点；上下文关系依据原生父链和焦点详情结构识别，未知保持未知。临时页不因无关区域的加载标记无限等待，稳定文本的关系未知可返回明确缺项；稳定但未展开的正文也及时返回其展开状态，保留已经识别的父链，不因此占满补齐超时。

parentState=unlinked 表示时间线没有可见回复关联，转为 post 模式并保留 relation=unconfirmed；none 才是 relation=standalone。不能在其他帖子的详情页复用相邻推荐帖作为独立帖或父帖。分析前更新页面可见的既有来源；只有角色仍引用原来源时替换，手动来源不被覆盖。终态事件在清理及 busy 复位后发送，避免用户看到操作按钮后新命令被旧周期静默丢弃。

每次主动操作先发准备阶段，完成输入校验及配置后再发模型分析阶段；计时从该执行周期开始，排队计时单独维护。事件不能在上一周期清理未完成时把用户的新操作静默忽略。

统一分析入口接受 bundle、当前连接、输出语言及取消信号。官方预置除 Claude 使用原生 Messages 外，使用厂商官方 Chat Completions 兼容接口；自定义连接支持 Chat Completions、Responses、Messages。参数按协议和厂商发送，不能把 DeepSeek 专用字段发给所有服务。流式仅用于接收，校验通过后才展示结果，丢弃思考内容。

严格检查结束状态、JSON 契约、来源和原文引用；不自动重试。接口失败仅展示安全错误，不暴露响应中的凭据。帖子 URL 可用于回看，模型仅接收文本、角色和媒体限制，不接收浏览器 cookies 或个人配置。

## 生命周期

每张卡片有独立控制器、端口、上下文和 Collector；后台按端口登记任务，不因同标签页新任务而取消旧任务。共享 FIFO 调度器限制两条解读操作同时执行，其余发出 queued 事件，取消排队项不会创建临时页或调用模型。进入执行槽位才启动 60 秒截止；补齐独立不超过 30 秒。阶段事件携带执行起点用于界面计时，等待用户补充释放槽位且无活动计时。

端口与心跳维持排队及活动任务，任务结束停止；关闭只取消对应端口，导航、原帖移除 / 复用、暂停站点或全局暂停取消受影响端口，最终清理各自插件临时页。内容脚本用 DOM 自然排版挂载独立 region，滚动与点击外部不改变任务。卡片创建即显示准备状态；页面快照与二次来源读取在同一准备流程内完成，读取异常转为可重试的界面错误并明确没有调用模型，不能留下空白正文。原生 SVG 图标不作为 HTML 回复连接线识别，不能假设全部 aria-hidden 元素的 className 都是字符串。设置入口由后台核验来源后打开 / 激活同一 options.html 页面，保留现有草稿。

临时页以 token / 过期时间登记到 storage.session；后台重启清理归属明确的页，用户已导航的页保留。设置变更对下次模型请求生效，不重算现有结果。首次安装 / 首次升级引导使用本地版本标记，避免每次启动重复打开。

## 0.3.1 实现入口

shared/settings.ts 负责可信存储与迁移；shared/models.ts 为型号源，shared/i18n.ts 为界面文案源，shared/sites.ts 判定来源 / 路径及排除已知私信和编辑入口。ui/reader.ts 复用 X / Reddit 适配与卡片；selection.content.ts 按用户站点授权动态注册。后台对公开配置、可信设置命令和网页分析端口分别核验，不向网页返回密钥。

设置任务使用可信页面端口及心跳，离开页面取消连接测试 / 型号请求。网页任务维护显式取消函数，后台主动暂停不能仅断开端口；临时页清理同时检查 url 与 pendingUrl，避免加载中遗留空白页，也保留已开始用户导航的页。

UI 使用共享 page.css，每页只加载一次。根 LICENSE 为许可维护源，构建脚本生成 public/LICENSE.txt 并打入安装包；SVG 为图标形状源，PNG 通过 icons 脚本生成。接口路径、语言和型号更改先保存，下次点击分析才生效。
